# Interkora Developer Documentation

The Sokora HTTP API, text-based API and API-based SDKs (collectively called “Interkora”, a fancy name for “interfaces to **inter**act with So**kora**”) are the foundation to building **integrations**, which are bots, apps and whatever one can dream of that interact with the bot in a read/write fashion.
